# Retail Sales Analysis and Customer Insights

## Project Overview

This project analyzes retail sales data to uncover customer purchasing behavior, product performance, and revenue trends using Python-based data analytics techniques.

The analysis includes data cleaning, exploratory data analysis (EDA), customer segmentation, sales trend analysis, and business insights generation.

---

## Objectives

- Understand customer purchasing patterns
- Analyze revenue across product categories
- Compare spending behavior by gender and age groups
- Identify top-performing product categories
- Generate actionable business insights

---

## Dataset

The dataset contains retail transaction records including:

- Transaction ID
- Date
- Customer Age
- Gender
- Product Category
- Quantity
- Price per Unit
- Total Amount

---

## Data Analysis Workflow

### 1. Data Loading
- Imported dataset
- Examined structure and data types

### 2. Data Cleaning
- Checked missing values
- Removed duplicates
- Validated data types

### 3. Feature Engineering
- Converted Date column to datetime format
- Created Month and Age Group features

### 4. Exploratory Data Analysis
- Customer Age Distribution
- Gender Analysis
- Product Category Analysis
- Revenue Analysis
- Correlation Analysis
- Monthly Sales Trend

### 5. KPI Summary
- Total Revenue
- Total Transactions
- Average Order Value
- Top Product Category

### 6. Business Insights
- Identified highest revenue-generating categories
- Analyzed customer spending behavior
- Evaluated sales trends over time

---

## Key Insights

- Electronics generated the highest revenue.
- Adult customers contributed the largest share of sales.
- Monthly revenue fluctuated throughout the year.
- Product pricing strongly influenced total sales amount.
- Male and female customers showed similar spending patterns.
